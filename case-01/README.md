# Case 01 — Análise Funcional de Alteração de Endereço

## Visão Geral

Este case apresenta uma análise funcional de uma jornada digital para alteração de endereço, estruturando o problema de negócio, regras, cenários e requisitos necessários para orientar a evolução da solução.

O cenário é fictício e foi desenvolvido exclusivamente para fins de portfólio profissional.

## Objetivo

Demonstrar a atuação de Business Analysis na transformação de uma necessidade de negócio em requisitos claros e estruturados, considerando comportamento da jornada, regras de negócio e cenários funcionais.

## Abordagem

A análise foi estruturada a partir das seguintes etapas:

- entendimento do problema e contexto da jornada;
- identificação dos envolvidos e necessidades;
- levantamento de regras de negócio;
- definição do comportamento esperado;
- análise de cenários e exceções;
- estruturação de requisitos funcionais;
- definição de critérios de aceite.

## Competências demonstradas

- Business Analysis
- Requirements Analysis
- Functional Analysis
- Requirements Elicitation
- Business Rules
- User Stories
- Acceptance Criteria
- Process Analysis

## Entregável

A documentação completa do case apresenta o raciocínio utilizado durante a análise, desde o entendimento inicial do problema até a definição dos requisitos e critérios funcionais.

> **Nota:** Este é um projeto demonstrativo. Empresas, dados, regras e cenários apresentados no material são fictícios e não representam informações confidenciais de organizações reais.
