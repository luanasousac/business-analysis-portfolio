# Case 05 — Análise de Abandono na Jornada de Contratação Digital

## Visão Geral

Este case apresenta uma análise de abandono em uma jornada digital de contratação, utilizando dados de conversão entre etapas para identificar o principal ponto de perda e direcionar a investigação das possíveis causas.

O cenário é fictício e foi desenvolvido exclusivamente para fins de portfólio profissional.

## Objetivo

Demonstrar a atuação de Business Analysis na análise de dados de uma jornada digital, identificando gargalos, estruturando hipóteses e definindo quais evidências precisam ser investigadas antes da recomendação de uma solução.

## Abordagem

A análise foi estruturada a partir das seguintes etapas:

- análise do funil da jornada de contratação;
- cálculo das taxas de conversão e abandono entre etapas;
- identificação do principal gargalo da jornada;
- separação entre o que os dados mostram e o que ainda não explicam;
- formulação de hipóteses para investigação;
- definição de perguntas para discovery;
- levantamento das evidências necessárias para validar as hipóteses;
- priorização da investigação;
- direcionamento dos próximos passos.

## Principais Hipóteses Investigadas

- elegibilidade do endereço;
- dificuldades no preenchimento dos dados;
- regras de validação;
- falhas ou indisponibilidade de integração;
- problemas de performance;
- problemas relacionados à experiência do usuário.

## Competências Demonstradas

- Business Analysis
- Data Analysis
- Funnel Analysis
- Requirements Elicitation
- Discovery
- Hypothesis-driven Analysis
- Root Cause Analysis
- Business Rules
- Process Analysis
- Data-driven Problem Solving

## Entregável

A documentação completa apresenta o raciocínio utilizado para transformar os dados da jornada em uma investigação estruturada, identificando o principal ponto de perda, formulando hipóteses e definindo as evidências necessárias antes da recomendação de mudanças.

A análise considera que correlação não significa causa: os dados permitem identificar onde ocorre a maior perda, mas a causa do abandono precisa ser validada por meio de evidências adicionais.

> **Nota:** Este é um projeto demonstrativo. Empresas, dados, regras e cenários apresentados no material são fictícios e não representam informações confidenciais de organizações reais.
