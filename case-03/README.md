# Case 03 — Integração para Consulta de Status de Pedidos

## Visão Geral

Este case apresenta a análise funcional de uma integração para consulta de status de pedidos em uma jornada digital, considerando a comunicação entre o Portal do Cliente, uma API de consulta e o sistema responsável pelos dados dos pedidos.

O cenário é fictício e foi desenvolvido exclusivamente para fins de portfólio profissional.

## Objetivo

Demonstrar a atuação de Business Analysis e Systems Analysis na definição de uma integração entre sistemas, transformando uma necessidade de negócio em regras, requisitos, mapeamento de dados e cenários funcionais.

## Abordagem

A análise foi estruturada a partir das seguintes etapas:

- entendimento do problema e do contexto da jornada;
- análise do fluxo atual (AS-IS);
- levantamento de perguntas de discovery;
- definição do fluxo futuro (TO-BE);
- levantamento das regras de negócio;
- definição de requisitos funcionais e não funcionais;
- estruturação conceitual da integração via API;
- mapeamento dos dados de entrada e saída;
- análise de cenários de erro e exceções.

## Competências demonstradas

- Business Analysis
- Systems Analysis
- Requirements Analysis
- API Integration
- Functional Analysis
- Business Rules
- Data Mapping
- Exception Handling
- Functional Documentation
- AS-IS / TO-BE Analysis

## Entregável

A documentação completa do case apresenta o raciocínio utilizado para estruturar a integração, desde o entendimento da necessidade de negócio até a definição dos requisitos, regras, dados envolvidos e tratamento dos principais cenários da solução.

> **Nota:** Este é um projeto demonstrativo. Empresas, dados, regras, integrações e cenários apresentados no material são fictícios e não representam informações confidenciais de organizações reais.
