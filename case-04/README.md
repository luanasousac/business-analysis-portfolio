# Case 04 — Consulta de Disponibilidade de Produto por CEP via API

## Visão Geral

Este case apresenta a análise de uma integração via API para consulta de disponibilidade de produto a partir do CEP informado pelo usuário.

O cenário é fictício e foi desenvolvido exclusivamente para fins de portfólio profissional.

## Objetivo

Demonstrar a atuação de Systems Analysis e Business Analysis na estruturação de uma integração entre sistemas, transformando uma necessidade de negócio em requisitos claros, regras de negócio, fluxo de integração e cenários funcionais.

## Abordagem

A análise foi estruturada a partir das seguintes etapas:

- entendimento do problema e da necessidade de negócio;
- identificação dos sistemas envolvidos;
- definição do fluxo de consulta por CEP;
- levantamento das regras de negócio;
- definição dos requisitos funcionais;
- análise da integração via API;
- mapeamento dos dados de entrada e saída;
- definição dos possíveis retornos da consulta;
- análise de cenários de sucesso, erro e indisponibilidade;
- definição de critérios de aceite.

## Competências Demonstradas

- Systems Analysis
- Business Analysis
- API Integration
- Requirements Analysis
- Functional Analysis
- Business Rules
- Data Mapping
- Exception Handling
- Functional Requirements
- Acceptance Criteria

## Entregável

A documentação completa apresenta o raciocínio utilizado para estruturar a consulta de disponibilidade de produto por CEP, desde o entendimento da necessidade de negócio até a definição do comportamento esperado da integração, requisitos, regras e principais cenários funcionais.

> **Nota:** Este é um projeto demonstrativo. Empresas, dados, regras, integrações e cenários apresentados no material são fictícios e não representam informações confidenciais de organizações reais.
