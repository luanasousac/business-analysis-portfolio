# Case 04 — Análise de Abandono na Jornada de Contratação Digital

## Visão Geral

Este case apresenta uma análise de dados aplicada a uma jornada digital de contratação, com o objetivo de identificar em qual etapa ocorre a maior perda de usuários e direcionar a investigação das possíveis causas do abandono.

O cenário é fictício e foi desenvolvido exclusivamente para fins de portfólio profissional.

## Objetivo

Demonstrar a atuação de Business Analysis na utilização de dados para identificação de problemas, formulação de hipóteses e direcionamento de discovery antes da definição de requisitos ou soluções.

## Abordagem

A análise foi estruturada a partir das seguintes etapas:

- análise do funil da jornada;
- cálculo das taxas de conversão e abandono;
- identificação do principal gargalo;
- separação entre evidências e possíveis causas;
- formulação de hipóteses;
- definição de perguntas para discovery;
- levantamento das evidências necessárias para validar as hipóteses;
- priorização da investigação;
- direcionamento dos próximos passos.

## Principais hipóteses analisadas

- elegibilidade do endereço;
- dificuldades de preenchimento;
- regras de validação;
- falhas ou indisponibilidade de integração;
- problemas de performance;
- problemas relacionados à experiência do usuário.

## Competências demonstradas

- Business Analysis
- Data Analysis
- Funnel Analysis
- Requirements Elicitation
- Root Cause Analysis
- Hypothesis-driven Analysis
- Discovery
- Business Rules
- Process Analysis
- Data-driven Problem Solving

## Entregável

A documentação completa apresenta o raciocínio utilizado para transformar dados da jornada em uma investigação estruturada, identificando o principal ponto de perda, formulando hipóteses e definindo quais evidências devem ser coletadas antes da recomendação de uma solução.

> **Nota:** Este é um projeto demonstrativo. Empresas, dados, regras e cenários apresentados no material são fictícios e não representam informações confidenciais de organizações reais.
